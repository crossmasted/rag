# 示例知识库文档

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合信息检索和文本生成的 AI 技术。它通过检索相关文档来增强大语言模型的生成能力，使回答更加准确和可靠。

## RAG 的核心流程

1. **文档处理**: 将文档切分成小块，并生成向量表示
2. **向量存储**: 将向量存入向量数据库（如 Qdrant）
3. **语义检索**: 根据用户问题检索相关文档
4. **上下文增强**: 将检索结果作为上下文提供给 LLM
5. **生成回答**: LLM 基于上下文生成最终答案

## RAG 的优势

- **准确性**: 基于真实文档生成，减少幻觉
- **实时性**: 知识库可随时更新，无需重新训练
- **可解释性**: 可以展示参考来源，增强可信度
- **成本效益**: 无需微调大模型，降低计算成本

## 技术栈

本系统使用以下技术：

- **前端**: Vue 3 + Element Plus
- **后端**: FastAPI + Python
- **向量库**: Qdrant
- **LLM**: Ollama + Qwen2.5
- **Embedding**: BGE-M3
